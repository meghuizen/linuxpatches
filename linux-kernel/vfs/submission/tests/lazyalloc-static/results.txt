Method: annot.py prints path_openat() with source lines (objdump -dlr);
trace2.py follows one path through it given the direction of every
conditional branch (dec-*.json, decided by reading the annotated
source line of each branch), and counts executed instructions inside
path_openat() (open_last_lookups(), do_open(), lookup_fast_for_open()
and step_into() are inlined there); calls are listed, not followed.
mapdec.py carries the decisions from one object to a near-identical one
by aligning the instruction streams.

  python3 annot.py namei-X.o path_openat namei-X.c > X.annot
  python3 trace2.py X.annot <start> "$(cat dec-X-<path>.json)"
